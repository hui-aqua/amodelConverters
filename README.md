# Sim2Blender

Turn AquaSim models and exported motion into Blender scenes with animated salmon.

## Choose how to use it

| Interface | Start here | Best for |
|---|---|---|
| **Desktop GUI** | Double-click **Start Sim2Blender.cmd** | Selecting files, reviewing timing, and building without terminal commands |
| **Command line** | `launchers/cli/run_workflow.py` through Blender | Repeatable commands, batch jobs, and automation |

Both interfaces use the same workflows and rendering code. Choose the interface you prefer, then choose the type of scene:

| Scene workflow | Required input | Structural motion |
|---|---|---|
| **Model + Blender physics** | AquaSim `.amodel` | Illustrative cloth and rope simulation in Blender |
| **AquaSim results replay** | Matching `.amodel` and results text export, e.g. `out.txt` | Exported AquaSim positions; optional salmon follow the same timeline |

Tested with **Blender 5.2**. Salmon default to **77.5 cm**, with **nominal 5 kg** body mass. Fish swimming is generated by this project; model-only cloth motion is not an AquaSim solver run.

## Option A: desktop GUI

1. Double-click [Start Sim2Blender.cmd](<Start Sim2Blender.cmd>).
2. Choose **Model + Blender physics** or **AquaSim results replay** from the workflow selector.
3. Browse to your model and select an output `.blend` file.
4. For replay, select the matching results text file, enter **Wave period** and **Source frames / wave**, and choose **Video FPS**. Wait for the calculated total frames and duration.
5. When adding fish, select the enclosing net walls and bottom. For the local `944ENR.amodel`, select **3 and 4**; exclude **5 and 6**.
6. Set salmon count, click **Build Blender scene**, then **Open scene in Blender**. Progress and cancellation are available in the window.

The first Windows launch installs PySide6 into a local `.venv` and needs internet. It can use Blender's bundled Python; subsequent launches require no commands. Blender is detected automatically, with its path available under **Advanced settings**. Close and reopen an existing GUI after updating the code.

**[Full GUI instructions](docs/guides/gui.md)** include setup on other platforms, saved settings, output logs and troubleshooting.

## Option B: command line

Run PowerShell from the project folder. No Qt installation is required.

```powershell
$blender = 'C:/Program Files/Blender Foundation/Blender 5.2/blender.exe'

# Build the included model example with Blender physics and salmon.
& $blender --background --factory-startup --python-exit-code 1 `
  --python launchers/cli/run_workflow.py -- model examples/models/winch_cage.amodel `
  --cap-openings --pin-top --fish-count 1000 --frames 120 `
  -o output/model_scene.blend
```

For replay, replace these placeholder paths and example wave values with your actual case:

```powershell
$model = 'inputs/models/my_cage.amodel'
$results = 'inputs/results/my_case_out.txt'

& $blender --background --factory-startup --python-exit-code 1 `
  --python launchers/cli/run_workflow.py -- replay-scene $model $results `
  --wave-period 5 --frames-per-wave 40 --fps 25 `
  --add-fish --fish-count 1000 -o output/replay_salmon.blend
```

Omit `--add-fish` for structural replay alone. Add `--membrane-ids` when the fish enclosure requires a subset of membranes. Existing script paths remain supported.

**[Full CLI instructions](docs/guides/cli.md)** cover component selection, separate replay/fish stages, options and automation.

## Replay timing: one clock for the cage and fish

- The application reads the number of structural samples from `out.txt`; node rows are not counted as separate frames.
- **Sample interval = wave period / source frames per wave.** Source frames per wave means exported structural intervals, not video frames.
- **Structural duration = (sample count - 1) * sample interval.** The first sample is at time zero.
- Fish and structure share the same video FPS, interpolated cage positions and frame range. The GUI shows source frames, duration, video/fish frames, and final-frame rounding.

Enter the actual AquaSim wave settings; physical wave period cannot be inferred from dimensionless Time labels. Rebuild both motion and fish after changing timing. **[Timing details and examples](docs/guides/timing.md)**.

## Where files belong

```text
Sim2Blender/
  Start Sim2Blender.cmd       Windows desktop shortcut
  launchers/
    gui/                     Desktop bootstrap and application launcher
    cli/                     Blender command-line launcher
  inputs/
    models/                  Your .amodel files (Git-ignored)
    results/                 Your matching text exports (Git-ignored)
  examples/                  Reference inputs; existing paths retained
  assets/fish/               Optional custom fish assets
  src/sim2blender/
    gui/                     PySide6 interface, inspection and job configuration
    cli/                     Shared Blender command dispatcher
    workflows/               Model, replay and fish orchestration used by both
    io/aquasim/              Model/results readers
    core/                    Shared paths and physical timing
    blender/                 Geometry, shading, physics and fish
    exporters/               OBJ, VTP and plotting
  scripts/                   Older entry-point wrappers and maintenance utilities
  tests/                     Python, GUI, Blender and saved-scene checks
  docs/guides/               Usage and technical guides
  output/                    Generated scenes, reports, logs and GUI settings
```

You can also select files elsewhere on your computer. Existing input files have not been moved. Keep each model paired with its own results; replay accepts the supported `Time [-] VID [-] X Y Z` text export, not `.avz` files.

Generated scenes and reports go to `output/` by default. GUI logs end in `.build.log`; replay verification reports use `.json`, `.replay.json` or `.fish.json`. The GUI asks before replacing scenes; CLI commands replace the requested output path. Use distinct filenames for variants.

## Viewing results and getting help

Open the `.blend` in Blender, press Space over the Timeline to play, and use Material Preview or Rendered shading for net openings. Press F12 for a still render.

| Issue | What to check |
|---|---|
| Nonmanifold enclosure | Select only enclosing walls/bottom; exclude attached flaps or internal sheets |
| Results mapping error | Use the matching model/export; initial source coordinates must match uniquely |
| Incorrect animation speed | Check wave period, exported intervals per wave and FPS; rebuild replay and fish |
| Blender cannot start | Choose its executable under GUI Advanced settings, or correct `$blender` |
| GUI build failed | Read the final error in the on-screen log or saved `.build.log` |
